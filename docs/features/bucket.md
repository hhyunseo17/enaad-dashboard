# 구간별 광고주 금액 분포

**코드**: `js/features/bucket.js` · **화면**: 메인 카드(차트) + `bucket` 상세 뷰 (KPI '광고주당 매출' 클릭 연결)

## 개요
월단위 광고주 매출을 금액 구간(1억↑ ~ 0.1억 미만 등)으로 분포 집계.
- 기준: 일반광고 + IMC.

## 핵심 함수
- `renderAdvBucketChart()` — 구간별 광고주수(막대) + 합산매출(라인) 이중축.
- `renderBucketPivotTable()` — 광고주수/평균매출/합계매출 3섹션(토글). 각 구간 행에 광고주 토글(펼치면 광고주별 월실적).

## 규칙/주의
- 광고주 행 펼침 상태: `expandedBucketAdvertisers` (기본 접힘).
- 평균/합계매출: 백만원 소수1자리.
- 연도 컬럼 접힘/펼침 지원.
