# MoM (전월대비 광고주 증감)

**코드**: `js/features/mom.js` · **화면**: 메인 카드(차트) + `momPivot` 상세 뷰

## 개요
당월 vs 전월 광고주별 매출을 비교해 신규/증액/유지/감액/중지 5분류.
- 기준: 일반광고 + IMC. 배분수익·1/N 제외.
- **연도·월 각 1개 선택 시에만** 동작(그 외엔 안내 문구). 메인 카드 클릭 → 상세 피벗.

## 핵심 함수
- `computeMoMData()` — 차트·피벗 공용. 5분류 버킷 + 합계 반환.
- `renderMoMChart()` — 전월/당월 막대. 마지막 카테고리에 datalabel.
- `renderMoMPivotTable()` — 카테고리 토글(기본 접힘), 헤더행에 합계, 펼치면 광고주.

## 규칙/주의
- 정렬: 신규·증액·유지 = 증감액 큰 순 / 감액·중지 = 감소폭 큰 순.
- 카테고리 헤더행 자체에 전월·당월·전월대비 합계 표시(별도 요약행 없음).
- 금액: 백만원 소수1자리, 0은 '-'.
